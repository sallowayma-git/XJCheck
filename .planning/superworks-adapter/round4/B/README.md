# round4 B：definition_text_nearest 脚号独立验证简报

**【门槛】无法判定，不能宣称 ≥98%。** 逐端口独立比对的可比对数为 0：51,898 个 definition_text_nearest 端口没有一个与端子导线直接相连（端子只在「二次原理图」页，部件端口只在「元件接线图/背板接线图」页）。下面的标签级指标只说明「端子排声明的标签-脚号在 SW 中有对应」，不是逐端口一致率。

## 一、统计（pin_validation.json）
| 层 | 口径 | 结果 |
|---|---|---|
| L1 直接导线链路 | 端子 → 共享导线 → 同页内部元件端口 | 可比对 66，一致 62，一致率 93.9%（全部为 instance_term_text）；nearest 可比对 0 |
| L2 标签级声明 | 端子排 L-N 声明在同项目同标签 SW 端口中有无对应（去 xref、去 strip_reverse） | 唯一声明 11,652；标签在 SW 中存在 4,791；命中 4,716，支持率 98.4% |
| 逐端口代理 | 同上，按 SW 端口反查 | nearest 3,552/10,947=32%，不具统计意义（声明稀疏） |

- L1 覆盖：2,166 声明的端子不在 SW；8,599 端子存在但无直连内部端口；887 有直连端口。
- L2 未命中 75 例：53 例为 CZ 块 E 脚（nearest 结果为 J1，E 由端子排文字回填）；22 例为 IN/OUT 端口名与数字脚号的格式差。若按端口名→脚号映射，支持率为 98.9%，剩余不一致仅 53 例，全部来自同一 CZ 块。
- L3 暴露：51,294/51,898（98.8%）的 nearest 选中文字是非默认对齐的 TEXT，text_ref 用 dxf.insert 而非对齐点；偏移中位 1.77、最大 3.36（task2_exposure.json）。

## 二、错误模式
1. 选中元件框内器件标记而非脚号：CZ 块 FEIDIAO-10A-Z-3-AC30 在 53 个项目中都选中 J1，距端口 8.3，落在 3×字高(9.0) 门限内。
2. 端口无邻近脚号时回退：同块 E 端口 nearest 失败，由 strip_reverse_corroboration 回填（循环依据，部件端口 59 个）。
3. 对齐点偏移（系统性）：距离、门限与并列判定都基于插入点，偏移与门限、并列阈值同量级，可能改变排序。
4. 命名口径：端子排写端口名（T2-IN2），SW 取圆内数字（2），形成 22 例假不一致。
5. 相邻线圈标签混淆（L1，非 nearest）：ZJ2-6 与 zj1-6、ZJ1-6 与 zj2-6，4 例。

## 三、建议修正规则（未在 src/ 实施）
- R1 文字取真实锚点：TEXT 且 halign/valign 非默认时用 align_point；MTEXT 按 attachment_point 换算；距离与并列判定统一用真实锚点。
- R2 元件体内文字不作脚号：nearest 候选排除完全位于元件框内部的文字，或把门限收紧到端口外侧标注区。
- R3 strip_reverse_corroboration 单列统计，不计入验证。
- R4 端口名与脚号映射：TERMPOINT 名（IN2）与显示数字（2）并存时，按映射比对。
- R5 建立真实逐端口真值：探索用连接标签线号（sw_connect_labels）桥接元件接线图与端子，人工核对 20–30 个块后再给出逐端口一致率（待验证方案）。
