## 1. 结论概要

- 同页共 4 处底端叠放（端口 2 下方，y=196 行），对应 PCM0002/PCM0005/PCM0008/PCM0012。两段文字的插入点只差 Δx≈0.02，对齐点（alignment point）完全相同（y=199，x=220/260/300/380），渲染位置完全重合。
- 两段都是模型空间里的独立 TEXT（不在 INSERT 内，不是 ATTRIB），都在 TEXT 层、图层开启、未冻结、非 Defpoints，都可打印，都没有 XDATA（无 LD_* 应用名）。
- 来源差异主要在句柄批次、绘制顺序，以及「B 段编号在别页作为装置端子出现、A 段编号在全项目别处不出现」。
- 倾向判断（非定论）：B 段（8n401/8n402/8n405/8n818）更可能是真实外部端子；A 段（8nB01/8nB12/8nB02/8nD02）更像较早版本遗留的标签。最终以用户对照原 DWG 为准。

## 5. 来源差异（ezdxf 读取 DXF 缓存）

- XDATA：两段都没有任何 XDATA 应用名，也没有 LD_*（SuperWORKS）标签。同一 DXF 中 TEXT 上保留的 XDATA 只有 `LDPARTLAYT_PART_HANDLE`（MARK 层说明文字），说明 DXF 导出并未丢弃 XDATA。两段都是「普通 TEXT」。
- 块属性：两段都不在 INSERT 内，也不是 ATTRIB；与 FJL 元件块（INSERT）无关。
- 句柄批次（同一图内的创建先后）：

- 文件头：全部 13 张 DXF 的 $TDUPDATE 相差毫秒级、$LASTSAVEDBY 均为 25788；13 张 DWG 的修改时间均为 2025-04-09 06:42。文件头和文件系统时间无法区分 F0012 是否被单独改过。$HANDSEED（0x136F8）与最大句柄（0x1369E）吻合。

## 7. 同页对照（同一页其他元件是否叠放）

- 底端：PCM0010（8n820，x=342.5）只有一条标签，同点（0.5 单位内）无第二段文字，无叠放。该元件的顶端只有 8KD4，也无叠放。它就是 Z-5 写的 pass 对照。
- 顶端：8KLP2-1、8KLP1-1,8KLP3-1、8QD2,8KLP2-1、8KD1 在 220/260/300/380 四处各有两条，文本完全相同（两批各一条），不构成矛盾，但说明标签集被复制过一次。
- MARK 层：每个元件表头的编号与型号（如 "15" 与 "FJL1-2.5/2A"）共用同一插入点，但字高分别为 1e-05 与 0.001，实际不可见，不构成视觉叠放。

## 8. 倾向判断与依据

倾向：**B 段（8n401 / 8n402 / 8n405 / 8n818）更可能是真实外部端子，A 段（8nB01 / 8nB12 / 8nB02 / 8nD02）更可能是较早版本遗留的标签。** 置信度中等。

依据：

1. 编号归属（最强的证据）：B 段五个编号（401、402、405、818、820）全部在该装置（PAC-861GA-GCN，8n 前缀）的原理图页上以 SuperWORKS 符号端子文字出现（F0007 出现 401/402/405，F0008 出现 818/820），且位置与 F0012 的底端顺序对应。A 段四个编号在全项目没有任何别处的对应。
2. 句柄序：B 批创建于 342.5 元件块插入之后，且包含 342.5 元件的底端 8n820 与顶端 8KD4；A 批早于 342.5 元件块，没有这两条。这与「A 是较早版本、B 是后补完整的标签集」一致。
3. 顶端标签两批都有，文本相同，说明标签集整体被复制或重输过一次；B 批在句柄上更晚。

反面证据与不确定性：

- 两段都没有 XDATA，SuperWORKS 连接标签元数据也没有覆盖这四个位置（Z-5 记录该项目 sw_connect_labels 为 0）。本 DXF 中无法借助 XDATA 判断。
- 句柄序只能说明创建先后，不能证明哪段是后来手改。也不能排除 B 批是从其他图复制后再修改的情况（复制会生成新句柄，也会呈现「较晚」的句柄）。
- 「F0007/F0008 的 401/402/405/818 属于本元件的 8n 端子」是依据前缀与符号标签的推断，未在原图上直接核对。
- 8nB12 与 8nD02 不符合 8nB0x 命名（Z-5 的概括不准确），但本项目中也没有任何证据说明它们是错的。

## 10. 对 Z-5 / A-1 口径的修正（只读结论）

- Z-5 「他页无对应 8n4xx」对带前缀的 8n401/8n402/8n405/8n818/8n820 成立，但对裸数字 401/402/405/818/820 不成立（见第 6 节）。A-1 的说明「401/402/405/818 作为裸数字出现在 S0007/S0008」与本次结果一致。
- 「8nB0x」应改为「8nB01、8nB02、8nB12、8nD02」。
- 底端比较应以对齐点为准（两段重合）；插入点差 0.02 不是区分依据。
