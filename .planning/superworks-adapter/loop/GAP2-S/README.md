## 2. 切开判据（`split_terminal_wires`，只在 DEV-INT 内）

线组是两段导线的并集，合并条件是间隙 ≤ 4.0，因此端子本体两侧的两根导线可能被合并。切开需同时满足：

1. **同一端子**：两个装置端子端口同文件、同 insert、端口标识（casefold）相同，且各自接触点落在同一线组的两段上。
2. **两侧分属两个端点连通分量**：线组成员仅由端点重合连通的分量恰为两个，两接触点各在一个分量上（否则 `components_not_two`）。
3. **间隙轴向**：两接触点在同一轴线上，横向偏移 ≤ 1.0。
4. **本体宽 ≥ 2.0**（`SPLIT_MIN_BODY_WIDTH`，否则 `body_too_narrow`）。本体宽 = 同 insert 两 TERMPOINT 中点距离，取实际距离。
5. **间距等于本体宽**：间距 = 两接触点距离，|间距 − 本体宽| ≤ 0.1 × 本体宽；间距 < 0.5 视为同一接触。
6. **间隙内无线**（`gap_crossed`）与**无连接圆点**（`dot_in_gap`）。
7. **可验证**：切开后两接触点必须落在不同的线组键上，否则撤销（`still_merged`）。

切开只改 DEV-INT 的线组映射；线组成员、配对、issue 不动。切开分段记为 `split_reason='terminal_body'`，并记录对侧端口 `split_partner_port_ids`。
