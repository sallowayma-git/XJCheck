- 来源分层的保守加权精度为 **65.59%**，设计加权 95% 置信区间为 **58.89%–72.28%**。保守值把截图无法判断的配对暂按不正确处理；若把全部不确定样本都算正确，上界为 100%。
- 六个通过配对来源层共抽查 227 例：161 正确、0 确认错误、66 不确定。首轮独立复核把 5 条临时错判改为 2 正确、3 不确定；其后按用户要求剔除了 p010、p032 的流水线自证，两例改为不确定。当前样本没有可确认并排名的错配形态；`top10_error_morphologies.csv` 与描述性 `top10_observed_error_morphologies.csv` 因此为空。不能据此声称总体没有错误。

- 问题项按规则类型加权估计中，约 **11,977–12,474 / 12,474（96.01%–100%）**需要人工核对。这里的“需要”指局部截图不足以闭环处置，不代替项目上下文审查。
- 原精度审计的 1,633 个唯一视觉案例均有一张对应截图和完整判定；其中 703 个复用了截图及几何均完全一致的既有证据，930 个重新渲染并盲审。0 张渲染失败，0 条标签缺失。另为待核验配对人工率新增 168 例随机分层截图审计；因它可能与原视觉样本重叠，不将两批简单相加。

## 抽样、截图和判定口径

原始精度样本从通过配对来源、待核验配对来源、pair kind、图纸类型、项目族及问题规则分层抽样；固定种子 `20261015`，抽样率 0.2%，每个大于等于 20 的分层至少 20 例，小分层全量核验。1,650 个分层分配合并去重为 1,633 个视觉案例。案例以配对/问题为单位，不是每层 20 张不同图纸。为修正待核验人工率，另于 `20261016` 按 `pair_kind` 重新抽取并逐张判定 168 例，完整 assignments、判定理由、截图与统计见 [`data/pair_kind_random_review/README.md`](data/pair_kind_random_review/README.md)。此前非随机 24 例 continuation 样本不用于该估计。

`correct` 表示截图能独立支持记录中的关系；`wrong` 仅表示截图直接反证身份或脚号；`uncertain` 表示局部截图缺少足够上下文。不得用同一流水线输出中的 endpoint、mapping 或 findings 行证明配对正确。五条初始错判经独立复核后有两条曾暂列 `correct`；按用户要求排除循环论证，这两条现均为 `uncertain`。更正日志保留每次标签迁移，原始分批审阅 CSV 保留。

此前提到的“错配形态消失”是 FP-FIX 退役旧 V1 `terminal_strip_lattice` 配对的结果：425 条 lattice 行在 p016–p021 不再生成。它不是本轮精度审计的修复成果；本轮样本没有确认任何通过错配形态。

截图逐例索引在 [render_index.csv](data/render_index.csv)，930 个新案例的联系表索引在 [contact_index_930.csv](data/contact_index_930.csv)。截图和联系表图片保存在工作区 `.tmp/precision_loop_20261015/current_baseline_screenshots/`、`.tmp/precision_loop_20261015/current_baseline_contact_sheets/`，索引中每张截图路径均已核验存在。逐例判定见 [judgments.csv](data/judgments.csv)；标签更正见 [judgment_corrections.csv](data/judgment_corrections.csv)。
