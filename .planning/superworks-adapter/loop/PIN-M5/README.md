# PIN-M5：原理图引脚 ↔ 元件接线图 PCL 逻辑端号的对齐评估（只读）

范围：只读调研。未修改 `src/`、`tests/`，未执行 git，未改动冻结 DXF 与 `corpus_manifest.json`，未在本目录之外留文件（中间产物见第 9 节）。
数据：round18 全量回放（77 项目，1745 页）的 `sw_*`、`sw_wire_routes`、`pairs`、`coverage` 表（经 `tools/00_load18.py` 合并为 `.tmp/pin_m5_work/all18.pkl`）；句柄扫描直接读取冻结 DXF（只读）。控制台 `PYTHONIOENCODING=utf-8`。

## 0. 结论

1. **原理图与接线图之间没有直接的句柄关联。** 对全部 1745 个冻结 DXF 扫描 207 万个 1005 句柄引用（XDATA 与 XRECORD），**0 个**在本文件之外解析（`tools/01_handle_scan.py`）。原理图符号的 `LD_SYMB2_LABEL` 与接线图部件的 `LDPARTLAYT_PARTLABEL_HANDLE` 各自指向同一图内的文字，不存在跨图互指。唯一的跨图引用是 PCL 线号中的文字 `未定义H:P_页`，它只指向别页的 装置端子 / 端子 实例，远端类别中没有 内部元件（第 1 节）。因此只能用“标签 + 端子身份”对应。
2. **标签对应成立。** 35963 个 Pop-S 引脚中，29183 个有有效标签，其中 28526 个（97.8%）在同项目的元件接线图 / 背板部件中有同标签部件，与 PIN-S 的 98% 一致（标签存在，不等于连接一致）。
3. **检验 A（PCL 对端能否解析到项目内已知端子身份）**：正式典设 92.7%，N2604 合同 92.6%，变压器测控柜 94.3%，110kV 变压器保护柜 82.6%，PAC-885G-H 82.5%（第 2 节）。
4. **检验 B（留出，真值为 Pop-X 与线圈/接插件的槽位脚号）**：TX（Pop-X）唯一预测 4229 个，**4210 个一致（99.55%）**，19 个不一致（无门控时的无偏估计）。加入“端子在同标签下不被多个引脚共享”门槛后 4197/4197 一致，但该门槛是在这 19 个错误上设计的，**4197/4197 为样本内结果，不是无偏估计**。TI（线圈/接插件）37/37。原理图导线另一端与同标签 PCL 远端的一致率：TX 正式典设 56.8%，N2604 64.1%；Pop-S 正式典设 44.0%，N2604 55.8%（第 3 节）。
5. **Pop-S 的 M5 身份几乎是循环的，不能准入。** Pop-S 的 M5 严格唯一预测 7322 个，其中 **7282 个**的 `标签+脚号` 与其自己端子身份相同（会被现有 F1 自环规则 `same_logical_identity_other_contact` 拒绝），**7318 个**的逻辑端号等于对端端子名的尾号（如 1N705 ↔ 705）。也就是说 Pop-S 上 M5 得到的“脚号”就是导线/端子号本身，不是独立的脚号证据。可准入的 Pop-S 非自环增量只有 **40 个**（第 4 节）。
6. **Pop-S 分桶**：内部元件 7294 个、线圈 28 个严格唯一；按块族 PWF191（开入）3413、PWF194（调压开关）1853、PWF192 588、PWF229（信号触点）488、PWF163 483 个，但其中绝大多数为自环。PWF208、PWF209、PWF318、PWF115 为 0（端子直连很少或标签缺失）。图面根本无脚号的类（PWF191、PWF229）上，PCL 只能给出“连接”，给不出可独立核对的脚号。
7. **目视（30 例，分层，见 `png/`）**：0 例不正确；两侧均可见一致 8 例；其余 22 例“不矛盾但有一侧不可见”（端子或远端文字在窗口外或跨页）。Pop-X 8 例的脚号与真值可见一致（第 5 节）。
8. **覆盖率**（COV-GAP 严格口径，基线 52494/82680 = 63.49%）：排除自环后，M5 可准入的增量为 **+489 个端子（TX 449、Pop-S 40）**，到 **64.08%（+0.59 pp）**。若不排除自环，理论上界为 72.88%（+9.39 pp），但其中 7282 个是自环，**不可采信**（第 6 节）。
9. **接入建议**：不接入 Pop-S 的 M5 身份与配对；Pop-X 的 M5 路径（TX）可作为 review 级候选、与 PIN-1 的 R1 合并，门槛见第 7 节。Pop-S 的连接信息可作为复核注记，不作为身份来源。

## 7. 接入方案建议（任务 6，不在本次修改范围内）

**接入点（建议）**：
- `src/dwg_audit/extract/superworks_loggen.py`：PCL 行的远端 SW 身份与文字身份已在 `sw_wire_routes`（PCL）中，无需新读 DXF；只需额外读取接线图部件的标签（`LDPARTLAYT_PARTLABEL_HANDLE`）以按标签归组。
- `src/dwg_audit/audit/superworks_extractor.py::_admit_wire_routes`：为 Pop-X 端（`insert_not_sw`，即 PIN-1 的 `identity_source=symb2_text_slot` 之外的端）增加候选来源 `pcl_layout`，只在下列门槛全部满足时生成 review 配对。

**准入门槛（TX 路径）**：
1. 同标签接线图部件的 PCL 行中，远端身份（SW 身份，或类别为端子的文字身份）与原理图导线另一端端子身份相同；
2. 该标签的候选逻辑端唯一（跨副本一致）；
3. 原理图端子不被同标签的其它引脚共享；
4. 不是自环（标签+脚号 ≠ 端子身份）；
5. 端子未被任何非 discard 配对消费；
6. 状态：review。升 pass 需要新的留出样本（不参与门槛设计）达到 ≥149 例全部正确（单侧 95% 下限 ≥98%）。

**Pop-S 路径**：不接入身份与配对。原因：自环比例 99.4%，逻辑端号等于端子尾号。若需要连接信息，可在复核清单中注记“同标签接线图指向该端子”，不写入 pairs。

**不要做的事**：
- 不要把 PCL 逻辑端号当作图面脚号直接写入身份（Pop-S 为循环身份）。
- 不要在无门槛的情况下使用 TX 的 99.55% 作为 pass 依据（错误率 0.45%，门槛后仍需独立验证）。
- 不要替换已有的 pass / review 配对（与 PIN-1 的约定一致）。

## 8. 对既有结论的修正

- PIN-S 第 6 节的 M5 “未测”：现已测。Pop-S 的 M5 可准入增量仅 40 个，远低于 PIN-S 设想的上界（18604 端子直连）。
- PIN-S 的 98% 标签对应：本次为 97.8%（28526/29183，含 657 个无部件的标签），结论一致。
- PIN-1 的 TX 路径：本次 M5 TX 对 Pop-X 的唯一预测在无门槛下 99.55% 一致，与 PIN-1 的 100%（46/46 目视）在样本量上一致，但 PIN-1 的 R1 与本次的 M5 路径并不完全相同，两者需要合并复核。
- PIN-ID 的 PCL 对端命中 79.8%：本次同口径（含文字身份）为 82.5%–94.3%，差异来自分母与身份来源的定义。
- ATTR-CENSUS 中 PCL 的“直线句柄 27967/28280 解析为 LINE”：本次未重验，仅引用。

## 9. 局限

- 目视为单人判定，未双盲；Pop-S 目视中 16/22 例并非两侧都能看到。
- TX 真值来自 Pop-X 槽位文字与序号，不代表通用 `N` 标签（TX 中 0 例）。Pop-S 的 98.5% 通用标签没有真值。
- 门槛在 TX 的 19 个错误上设计，4197/4197 为样本内结果。
- 连接一致率偏低（44%–64%），表示约一半的原理图引脚没有可用的 PCL 对应；覆盖率增量受此限制。
- 句柄扫描只覆盖 1005 句柄，字符串句柄（code 1）未重扫，沿用 ATTR-CENSUS。
- 数据为冻结 DXF 缓存（未重新转换 DWG）；round18 回放结果。
