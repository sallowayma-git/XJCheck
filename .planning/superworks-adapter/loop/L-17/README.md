## 2 语义结论
@ 是版式标注记号，不是端子身份的一部分：剥离首尾 @ 后应与同名无 @ 端子等价。但不能裸名全局合并（见 3、4）。
证据：
- 去 @ 后的身份在同项目中能找到无 @ 文字：811/895（91%），多为二次原理图（如 S0008 的 1-42TD1）。
- 背板虚拟端子表 106 页中 104 页的 TD 标签全部带 @，且按列统一（S10、S07）；仅 2 页混合（p072 S0017 即 S04；另有 p073 S0012）。
- 屏端子图裸 "@" 紧跟装置侧 42nCOM 标签，同一 COM 段引脚统一带 @（S03），是版式符号，不是逐端子属性。
- 359,750 个文字及 doc/、src/ 中无任何图例或说明解释 @（"跨柜/虚拟端子/柜外" 命中 0）。
- 仓库已有先例：`backplate_components.py:907`、`page_extractors.py:3036` 均用 `strip("@&")`。
未证实：@ 是否表示"柜外/外接"等含义。图纸无图例，本结论只针对身份，不针对含义。

- D 81：项目内无同名无 @ 对照（如 p003 `8n1208 @`）。

## 4 修复点与影响（未改代码）
- 主修复点：`src/dwg_audit/audit/superworks_extractor.py:782`，函数 `extract_superworks_pairs`（:476）中 `values=[normalize(v.strip().strip("&")) ...]` 只去 "&"。改为 `strip("@&")`（与 backplate_components.py:907 一致），或只去首尾 @。`external_endpoint_raw` 保留原文以便审计。
