# SuperWORKS 识别优化循环：待解决问题清单

## 循环流程

每一轮按以下顺序进行：

1. 审计剩余的 issue。
2. 选出证据充分、不会放过真实问题的优化切片（fail-closed），多个切片之间修改的文件互不重叠。
3. 派 Haiku 子代理处理每个切片：查看 DXF 和截图 → 通用修复 → 单元测试 → 单项目或单页验证。
4. 主线程复核截图和证据。
5. 跑全量测试，必要时全量回放。
6. 更新本清单，做范围明确的提交并推送。
7. 清理不再复用的过程文件。

**约束**

- 禁止按项目、取值或句柄写特判。
- 禁止对 SuperWORKS 来源整体豁免。
- 只允许减少误报，不得删除真实问题。

**提交与推送**：推送到分支 `superworks-loop`，不直接推 master。
